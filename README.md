# Motorsport Race Analytics API

A backend-only REST API built with **Laravel**, designed to manage motorsport data such as drivers, race schedules, teams, results, and lap times.  
This project is focused on learning backend engineering, clean REST architecture, and building a fully separated REST API (no frontend).

> **Status:** 🚧 Project is still in development.

---

## 🚀 Features (Planned & In Progress)
- CRUD endpoints for drivers, teams, races, and results  
- Lap time tracking  
- Simple analytics (fastest lap, average lap, performance summary)  
- Clean and scalable database design  
- API documentation using OpenAPI / Swagger / Scribe  
- Unit & Feature testing (PHPUnit / Pest)

---

## 🛠 Tech Stack
- **Laravel** (PHP Framework)  
- **MySQL / PostgreSQL**  
- **Scribe / Swagger** for API documentation  

---
## 📌 Purpose
This project is created for learning and practicing:

- REST API design  
- Clean architecture & service layer pattern  
- Test-driven development workflow  
- Backend development separated from frontend  
- Designing scalable data structures for motorsport analytics
